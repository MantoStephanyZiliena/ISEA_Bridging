 # Reflection

## Advantages of Using Virtual Machine
One advantage I can think of using a Virtual Machine is being able to use another operating system with the use of only one computer, I don't need to use another computer just to run a different operating system. The use of virtual machine will also reduces risk of affecting anything from my main operating system, which is really good for exploring and learning about the use of other operating system.

## Challenges I faced
For me, the challenge I faced was installing Ubuntu inside the VirtualBox, It took me so long that I was left behind doing the first lab activities. Installing the VirtualBox was fast but installing Ubuntu inside it took a lot of time. I was even about to download VMware because I saw most of the other students uses it. But I decided to just restart my Ubuntu installation by increasing the amount of memory and processors I will use to make the installation faster. After few more minutes of waiting, it finally downloaded which I was happy about and I was able to catch up with the lab activities.

## What I learned
Doing this first lab of ISEA, I learned that I can actually use a different operating system on my computer without changing anything and how I can use or allocate my memory and processors to do a specific task much better. Through this first lab, I was able to use Linux and learn more about it, from using a VirtualBox to installing and setting Ubuntu.
